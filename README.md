# Ensemble-Techniques-for-Customer-Prediction
Predict customer behavior and signal quality using multiple ensemble classifiers to improve accuracy and robustness.

Tools & Technologies Used :-
Python, scikit-learn, XGBoost, pandas, numpy

Steps / Workflow :-

Preprocessed and split dataset into training and testing sets
Applied Decision Tree, Random Forest, Bagging, AdaBoost, Gradient Boosting, and XGBoost classifiers
Performed hyperparameter tuning with GridSearchCV for the Decision Tree
Evaluated models using accuracy, F1-score, precision, recall, and confusion matrix

Results / Output :-
XGBoost achieved the best accuracy (88.5%) with balanced class predictions. Confusion matrices and classification reports confirmed improved performance.

Conclusion / Insights :-
Ensemble methods enhance prediction accuracy and prevent overfitting, making the model reliable for business recommendations.
